🚀 Gravity Simulator 3D - User Manual & Hotkeys

Navigation & Controls

  • Left Click Drag: Orbit 3D perspective camera
  • Right Click Drag: Pan target focal point
  • Mouse Wheel: Zoom in / out
  • Left Click on Body: Inspect orbital elements and maneuvers
  • Left Click + Drag (in Spawn Mode): Aim slingshot velocity vector and launch

Hotkeys

  • Space: Pause / Resume physics simulation
  • , / . (or < / >): Decrease / Increase simulation speed (by active step: ±0.1x, ±0.5x, ±2.0x; Hold Shift for fine ±0.1x)
  • \: Reset simulation speed to 1.0x (Normal)
  • 1 - 9, 0: Instant preset selector
  • B: Toggle Barnes-Hut Octree ($O(N \log N)$ vs Direct $O(N^2)$)
  • P: Toggle 3D Spacetime Curvature Potential Grid
  • O: Toggle Gravitational 3D Vector Field (32x32 needles)
  • [ / ]: Decrease / Increase Spacetime Grid Scale (0.5x - 3.5x)
  • L: Toggle Particle Velocity Glow Mode
  • G: Toggle 1PN General Relativity Precession
  • M: Toggle 2D Tactical Viewport
  • H: Toggle Continuous Gravitational Heatmap in 2D
  • R: Reset Camera viewpoint
  • N: Lock Camera to Nearest Object
